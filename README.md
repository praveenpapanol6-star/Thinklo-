# TINKLO Shopping Website

A responsive starter storefront for TINKLO, designed to work on phones and computers.

## Included
- Product cards, categories and search
- Shopping cart with quantity controls
- WhatsApp order enquiry/checkout
- Responsive layout
- No server or database required for this starter version

## Preview
Open `index.html` in a browser.

## Publish free with GitHub Pages (phone-friendly)
1. Sign in to GitHub and open your TINKLO repository.
2. Upload the files from this folder (`index.html`, `style.css`, `app.js`) to the repository root.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Choose branch **main**, folder **/(root)**, then Save.
6. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages section.

## Important before launch
- The products and prices in `app.js` are demo entries. Replace them with your real products, prices and descriptions.
- WhatsApp checkout is set to the business number supplied for TINKLO: +91 6364608691.
- Email shown on the page: tinklogadgets@gmail.com.
- This starter does not yet process online payments, store orders in a database, or provide an admin dashboard. WhatsApp is used to confirm orders manually.
- Add your shipping, returns, privacy and terms policies before accepting public orders.
